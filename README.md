# MLE-Coding-Interview-Prep

## Overview

This repo is a collection of practice problems for Machine Learning Engineer (MLE) coding interviews, along with solutions and setup for working through them locally.

## Setup

Create and activate a virtual environment (Python 3.12):

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
